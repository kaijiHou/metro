# 内置城市线网

截至 2026-10-07，从[高德地铁图](https://map.amap.com/subway/index.html)当前使用的城市目录和线网接口获取并转换了 **58 个城市线网、397 条线路或支段**。完整城市、线路数、站点数和每条数据的来源 URL、SHA-256、获取时间在 [`public/transit/catalog.json`](../public/transit/catalog.json)。其中武汉 13 条线路、289 个站，包含 12 号线。城市集合包括大陆、香港、澳门与台湾；跨市线路有的按一个城市线网归集，部分也在相邻城市入口出现。这里的“城市线网”包含地铁、轻轨、市域线、磁浮等城市轨道服务；不表示有 58 个独立的地铁运营主体。

更新脚本读取每条线路的运行标志、站点运行标志、站名、站序、换乘站 ID、线路颜色和站点坐标，排除源数据标为未开放的站点及缆车。大陆、香港、澳门的高德坐标转换为底图使用的 WGS84；台湾坐标保持源值。线路直接连接相邻站点，**不代表实际隧道或轨道的精确走向**。环线首尾闭合，重复路线分支可拆为支段，换乘站保持同一站点引用。

快照获取日期反映本项目下载时间，**不代表运营方核实或更新的日期**。新开、暂停、改名或施工调整请以运营方公告为准。页面会显示获取日期和来源。内置快照经检查后提交到仓库；用户第一次选择城市时复制为可编辑项目，后续改名、移动、增删会单独保存在浏览器里。重新抓取快照不会自动覆盖用户修改。

Phase 3 读取时将内置线路标记为 `existing`、`visible: true`、`locked: true`。用户解锁后只编辑浏览器副本；原始 JSON 保留。多方案保存完整项目快照，新建方案从当前内置现状起步；快照更新不会自动覆盖已保存方案。若线路或站点 ID 发生变化，必须先核对旧方案再决定迁移，不能静默删掉规划内容。项目代码的 MIT 许可不扩展到第三方源数据，公开仓库继续保留用户要求的内置数据，同时仍应复核适用的再分发条款。

重新生成：在项目根目录用 Python 3.10+ 执行 `python scripts/update-transit.py`。脚本限制同时两个数据请求，全部城市转换成功后才替换正式快照；原始响应留在忽略版本控制的 `validation/transit-source/` 供复核。`python scripts/update-transit.py --cached` 可用已有原始响应复验转换。更新后运行单元测试和浏览器流程，并核对新增或退出的线路。
