# 真实线网数据说明

真实城市线路的项目结构和编辑能力曾完成验证，但当前公开仓库**不再分发第三方城市轨道交通快照**，也不提供批量抓取脚本。打开城市仅定位地图，不自动载入线路；用户仍可自主绘制或导入已有的合法项目 JSON。

项目格式保留站点、控制点、线路、换乘引用、闭合线路及可选 `cityId` 等能力，以便读取旧项目和未来接入合适数据。恢复真实线网选择功能之前，需要确认数据来源具有明确开放许可、得到授权，或由用户自行提供有权使用的数据，并补齐来源、更新日期与验证流程。

先前发布过的第三方快照仍可能存在于 Git 历史；本阶段只从最新版本移除，不改写已推送历史。现有浏览器项目不会被主动清除。建议先导出 JSON 备份，尤其是此前修改过真实城市线路的用户；城市切换入口已暂时关闭。
