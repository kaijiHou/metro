# 县级市足迹与省份清单（2026-10-17）

## 本次交互

市级地图与县级市统一显示：339个原有市级单元始终加载，武汉、直辖市、港澳等不会因为新增县级市而消失。搜索同时支持市级与县级市，普通县和市辖区隐藏。仙桃等无地级父市的省直辖县级市在全国图也保留自身轮廓和点亮颜色；其余县级市放大到6.5级后按视野载入相关几何，悬浮显示“县级市 · 上级市 · 省份”。县级市标签使用代表点，避免多面几何重复文字。

点亮洪湖市，会将整个荆州市作为已去地区着色，并计入市级及省份统计。父市状态由县级市记录推导，不自动创建市级记录，不复制日期或照片。父市详情说明点亮来源；只有最后一个已去子市取消且父市没有单独点亮时，父市才熄灭。统计对父市去重，省直辖县级市作为独立城市计入。单独点亮父市不会反向点亮所有子市。台湾当前没有已核对市级/县级市边界，保留省级轮廓并说明缺失。

“我的省份足迹”分“去过的省份 / 未去过的省份”，分母为34个省级地区。任意已到过的市级或县级市记录使所属省份计为去过；取消某一条时，若该省还有其它到访记录，仍为去过。按钮列出已去县级市数量和已点亮市级地区数量，点击可定位该省。未去过指本地资料尚未点亮，不是定位系统对真实行程的判断。

## 边界、名称与覆盖

几何来自 geoBoundaries gbOpen CHN ADM3，固定提交9469f09，来源Lee Beryman/OpenStreetMap，ODbL1.0。API元信息标记表示年份2017，源简化文件实际有2864个要素（不是照抄元信息2867）。SHA256见 `public/footprint/counties/sources.json`。

中文名参照 modood/Administrative-divisions-of-China 固定提交c49d495b40ac73eb1a66f6eeae5f8fd10696f035，WTFPLv2。处理时核对几何省份、同省唯一拼音名称、上级市；有歧义或冲突不纳入。省市交叠比例、原英文名称、参考代码及排除原因逐项记录在audit.json。省、市归属核对是资料整理，不代表当前法定边界认定。

共2467个县级候选单元通过核对，397个源单元排除。**界面只显示其中352个县级市**，涉及26个省级地区。352不是全国当前县级市总数；397也不是缺失县级市总数。县级市以中文表的县级单元名称及代码层级筛选，排除代码以00结束的东莞、中山、儋州地级市占位条目。

几何按省分文件，所有县级衍生数据约14MB，按视野/所选省份读取并缓存，仅将县级市送入地图；全国初始视图加载完整已有市级几何；省直辖县级市相关省份直接载入，其余县级几何在放大后按视野载入。轮廓、地名与资料继续可由本机服务离线读取。详细道路离线地图包不属于本次改动。

完整许可在同目录ODbL-1.0.txt和NAME_DATA_LICENSE.txt，界面及数据README保留署名。源几何及衍生数据库按ODbL提供；应用代码MIT不覆盖这些数据库。
