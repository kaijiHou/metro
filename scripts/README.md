# 启动脚本

本目录存放本地启动入口，不存放业务代码、依赖包或运行产物。

Windows 用户双击 `start-metro.cmd` 即可启动项目并打开浏览器。需要已安装 Node.js 并在项目根目录执行过 `npm ci`。

地址固定为 `http://127.0.0.1:5173/`。已经启动时只打开页面；首次启动后请保留运行窗口，关闭窗口即停止服务。端口被其他程序占用时会提示失败，不会自动切换到其他端口。

`update-transit.py` 按需从高德地铁图当前接口重新生成全国线网快照；使用 Python 3.10+、项目内的 `public/transit/` 与 `validation/transit-source/`，不会更改浏览器里的个人规划。无需日常启动时运行。
