# 旅行只读资源

仅存放许可明确的行政边界、城市目录及系统默认图片，禁止个人照片/旅行记录/token。

边界：OCHA/HDX COD-AB China、ITOS，CC BY 3.0 IGO。原始SHP与码表PCODE精确连接，按市级筛选、几何验证/取整、莱芜并入济南；339支持单元/33分组，34个省界仅作显示。来源、SHA256和处理见sources.json、mapping-audit.json和docs/FOOTPRINT_DATA_SOURCES.md。不是现行法定边界或全国市县全覆盖。

系统图仅武汉黄鹤楼，GoodFreePhotos，Public Domain/CC0；来源/使用条款/字节校验见sources.json。其它城市没有默认实拍，使用文字占位。用户上传图片不属于本目录。
