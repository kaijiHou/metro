# 城市轨道交通数据

由 `scripts/update-transit.py` 从高德地图公开地铁页面当前使用的接口生成。每个城市文件含来源 URL、获取时间、原始响应 SHA-256 和可编辑的项目数据；`catalog.json` 为城市索引。获取日期不等于运营方的线路更新日期。

站名、站序、颜色与站点坐标来自第三方；源中的未开放线路、站点及缆车不纳入。大陆和港澳坐标从 GCJ-02 转换为底图使用的 WGS84；台湾坐标保持原值。线路以站点间直线表示，不是实际隧道或轨道的测绘路径。环线保留首尾连接；同一线网跨越多个城市时可通过城市别名进入。

代码的 MIT 许可不授予第三方数据的额外权利。数据来源：[高德地铁图](https://map.amap.com/subway/index.html)。请遵守数据提供方适用的使用条款，勿将快照标记为官方实时数据。

此目录只存生成的城市数据与索引，不存用户规划、原始响应和临时日志。
