# 内置补充数据

本目录存放可公开、可溯源的应用数据，不放个人项目、照片、数据库或临时下载。

`trams.json` 是独立的武汉（车都T1、光谷L1/L2/L3）、南京（河西、麒麟）电车补充，© OpenStreetMap contributors，按 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) 提供。OSM WGS84站位，不是精确轨道。来源URL、原始响应SHA256、获取时间、人工核对链接和换乘对应表随数据发布。原有58份地铁快照没有改动。

复现：先运行 `scripts/fetch-trams.py`（或下载 tram-data 工作流产物），再运行 `python scripts/build-trams.py <原始数据目录>`。原始下载放 `validation/tram-source/`，不放这里。

校正：车都T1两方向车城大道节点原被OSM误标为滨湖社区；按完整22站名单修正。L1两方向17/15站；L3南向15站，北向依照L1单向段与L2共线段拼接13站，须按运营公告复核，不是时刻表。换乘仅使用列出的人工核实对应，不按同名或距离自动连接。异名换乘保留电车站名为别名，统一使用原地铁站ID/位置，换乘耗时采用估算。

武汉光谷四路、光谷五路的地铁与电车站相距约1.6—2公里；南京天保街同名站也不是同一站位。它们保留独立ID，搜索结果以所属线路区分，不做未经核实的步行连接。南京石杨路与10号线出站换乘已核实合并。

暂不发布抓取的苏州、大连、黄石资料：存在顺序、缺站或终端回路歧义；不能把原始成员顺序直接当作可靠服务。北京西郊线、佛山南海电车原快照已有，本应用在查询中识别为电车，不重复新增。此补充不是全国完整电车名录，也不代表实时开放状态。
